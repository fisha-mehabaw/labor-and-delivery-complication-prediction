# Labor and Delivery Complication Prediction Using Machine Learning

**MSc Thesis Project | Predictive Analytics · Healthcare Machine Learning · Classification**

This repository contains the experiments for an MSc thesis investigating whether machine learning models can predict **labor and delivery complications** from **antenatal care (ANC) data**. It compares classical supervised classification methods and studies the effect of class imbalance handling with the Synthetic Minority Over-sampling Technique (SMOTE).

> **Research prototype:** This project is for academic and exploratory research. It is **not** a validated clinical decision-support system and must not be used to make patient-care decisions.

## Objectives

- Prepare antenatal-care records for supervised classification.
- Compare **Random Forest**, **Logistic Regression**, **Support Vector Machine (SVM)**, and **K-Nearest Neighbors (KNN)**.
- Investigate the effect of **SMOTE** on the minority complication class.
- Assess classification using accuracy, precision, recall, F1-score, confusion matrices, and ROC-related metrics.

## Dataset

The repository includes `anc dataset.csv` and `Fish - Copy.csv`. The Random Forest notebook loads **`anc dataset.csv`**, encodes the `Presentation` feature using dummy variables, and predicts the `Complication` target.

In the recorded Random Forest experiment, the dataset contains **2,000 observations**, divided into a **stratified 70% training / 30% test split** (1,400 / 600 records). The unbalanced training classes contain 1,176 class-0 and 224 class-1 records; SMOTE increases class 1 to 1,176 in the training data.

**Data governance:** Before reusing or redistributing patient-level data, verify consent, authorization, de-identification, and applicable data-sharing requirements. Availability in a public repository is not itself evidence that unrestricted redistribution is permitted.

## Recorded results: Random Forest

The following values are **saved notebook outputs**, not newly reproduced benchmarks.

| Test metric | Original training data | SMOTE-balanced training data |
|---|---:|---:|
| Accuracy | 95.67% | 96.00% |
| Precision (class 1) | 88.04% | 82.73% |
| Recall (class 1) | 84.38% | 94.79% |
| F1-score (class 1) | 86.17% | 88.35% |
| Reported ROC AUC | 91.10% | 95.51% |

**Interpretation:** In this experiment, training with SMOTE substantially increased recall for the complication class, with some reduction in precision. This trade-off matters in risk-screening research because missed complications and false alerts have different consequences.

**Evaluation caveat:** The notebook calculates its reported ROC AUC using **predicted class labels**, not probabilities or decision scores; these figures should therefore not be treated as conventional score-based ROC-AUC estimates. Future evaluations should use prediction scores and report confidence intervals and external validation.

## Getting started

### 1. Clone the repository

```bash
git clone https://github.com/fisha-mehabaw/labor-and-delivery-complication-prediction.git
cd labor-and-delivery-complication-prediction
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it:

**Windows (PowerShell)**
```powershell
.venv\Scripts\Activate.ps1
```

**macOS / Linux**
```bash
source .venv/bin/activate
```

### 3. Install packages

The notebooks use the Python data-science ecosystem, including scikit-learn and imbalanced-learn. A starting set of packages is:

```bash
pip install notebook pandas numpy matplotlib seaborn scikit-learn imbalanced-learn
```

> The repository does not currently include a pinned `requirements.txt`. These commands install current package versions, which may require minor updates to older notebook code (for example, the legacy `SMOTE.fit_sample` API should be replaced with `fit_resample`). For exact replication of saved historical outputs, document and restore the original environment.

### 4. Run the notebooks

```bash
jupyter notebook
```

Open a model notebook such as `Randomforest.ipynb` and run the cells in order. Keep `anc dataset.csv` in the repository root so the relative file path resolves.
